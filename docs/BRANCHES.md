# Branches GitHub (lisibles)

Panda n’a **pas besoin** d’une forêt de branches.

| Branche | Rôle |
|---|---|
| **`main`** | L’app. **Vercel déploie uniquement celle-ci.** |

Les autres branches (préfixe `cursor/…`) sont du travail en cours. Tu n’as **rien à y toucher** pour mettre le site en ligne.

**Ne crée pas** `dev`, `prod`, `lee`, etc.
