# 05 — Conversation libre

Mode **Libre** : tu parles comme à un ChatGPT. **Aucune écriture** en base tant que tu n’as pas changé de mode (et validé une carte).

---

## A-t-il le droit de **lire** tes tâches pour répondre ?

```
[ ] Oui : on lui envoie le même extrait compact (id, titre, butoir, durée…)
[ ] Non : il ne sait rien de la base (plus privé, plus bête)
```

**Conseil :** Oui. Sinon « t’as quoi d’urgent ? » en Libre est faux. Coût tokens : le même extrait que les autres modes, déjà prévu.

## A-t-il le droit de **proposer** une carte (créer une tâche) en Libre ?

```
[ ] Non. Il dit « passe en À faire / Reçu / … »
[ ] Oui, une carte, tu valides comme ailleurs
```

**Conseil :** Non en v1. Sinon le sélecteur de mode ne sert plus et il « range » ta vie dès que tu rumines.

## Sujets interdits (optionnel)

```
- (ex. pas de conseil médical, etc. si tu y tiens)
```

## Exemples de messages Libre (2 suffisent)

Ce que tu veux comme réponse, en une ligne.

```
Moi : …
Lui : …
```

```
Moi : …
```
