# 5 — Relances et bouton Valider

**Relancer** = tâches `en_attente`, du plus **vieux** au plus récent (date d’entrée en attente).

Dis si c’est bien ça, et si une relance **avant X jours** est ignorée (ex. pas relancer si contacté hier).

**Exemple :**

```
Relancer = en attente, plus ancien d’abord
Ne pas proposer si contacté il y a moins de 3 jours
```

**Valider :**

Si tu envoies un 2ᵉ message **sans** avoir cliqué :

```
[ ] la nouvelle carte remplace l’ancienne
[ ] on bloque tant que je n’ai pas choisi
```

Si un collage crée **3** lignes (2 contacts + 1 tâche) :

```
[ ] tout valider d’un coup
[ ] je peux décocher des lignes puis valider le reste
```

**Exemple :**

```
2e message : remplace l’ancienne carte
3 lignes : je décoche puis je valide
```
