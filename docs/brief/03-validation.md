# 03 — Carte « proposition » (1 clic)

Après **chaque** message agent (sauf Libre, si tu le dis dans `05`), une carte, pas une écriture silencieuse.

```text
┌─────────────────────────────────────┐
│ Proposition                         │
│ • Créer : Contacter plombier …      │
│ • Durée 15 · Perso · pas de butoir  │
│                                     │
│ [ Valider ] [ Modifier ] [ Annuler ]│
└─────────────────────────────────────┘
```

---

## Questions (coche une ligne par bloc)

### Si je tape une 2ᵉ phrase **avant** d’avoir validé

```
[ ] La nouvelle proposition REMPLACE la précédente
[ ] Les deux s’empilent (je valide dans l’ordre)
[ ] Interdire d’envoyer tant que je n’ai pas choisi
```

**Conseil :** première case. Sur téléphone, empiler 4 cartes = le chaos.

### Modifier

```
[ ] Ça ouvre les champs de la carte (durée, date, titre…) puis Valider
[ ] Ça envoie un message du type « non, mets 30 min » dans le chat (nouvelle proposition)
[ ] Les deux
```

**Conseil :** les deux. Tap sur un champ = correction rapide ; une phrase = cas tordu.

### Plusieurs changements d’un coup (mail = 3 tâches)

```
[ ] Une seule carte, tout Valider d’un coup
[ ] Une carte par tâche, je coche
[ ] Une carte, avec des cases à décocher (j’enlève une ligne, je valide le reste)
```

**Conseil :** troisième. Un mail « devis + RDV + facture » : tu décoches la facture, tu valides le reste.

### Rédiger (mail / ODJ) — le bouton Valider veut dire

```
[ ] Juste « j’ai lu » (rien en base) + je copie le texte moi-même
[ ] Copier le texte **et** proposer « sauver dans notes » comme 2ᵉ bouton
[ ] Toujours sauver dans notes
```

**Conseil :** deuxième.

### Champs éditables sur la carte (sans ouvrir toute la fiche Liste)

Coche ce que tu veux pouvoir **corriger au pouce** avant Valider :

```
[ ] description
[ ] durée
[ ] perso / pro
[ ] butoir
[ ] contact (nom, tél, mail)
[ ] attente de retour
[ ] notes (aperçu)
[ ] liens
[ ] « c’est une sous-tâche de … » (choix d’une tâche parente)
```

**Conseil :** tout sauf notes longues (2 lignes max sur la carte ; le pavé se voit en Liste).

### Liste (onglet visualisation)

Déjà prévu : corriger / archiver à la main. Confirme :

```
[ ] Je garde l’onglet Liste EN PLUS du chat à propositions
[ ] Je ne veux que le chat (pas de liste) en v1
```

**Conseil :** garder la Liste. C’est ton filet si l’IA se plante.

### Archiver depuis une proposition

```
[ ] Oui (l’IA peut proposer d’archiver, je clique)
[ ] Non, archivage seulement dans l’onglet Liste
```
