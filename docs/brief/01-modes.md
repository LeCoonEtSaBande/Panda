# 01 — Modes (sélecteur)

Coche, renomme, fusionne. **Un seul mode actif** à l’envoi du message.

Sur téléphone je te conseille des **pastilles**, pas un menu minuscule :

`À faire`  `Fait`  `Reçu`  `Envoyé`  `Rédiger`  `Libre`

---

## Tes modes proposés → ma lecture

| Pastille (proposition) | Ce que tu as dit | Outils côté IA (idée) | Tu colles souvent… |
|---|---|---|---|
| **À faire** | Ce que je dois faire | créer / préciser une tâche (proposition) | une phrase |
| **Fait** | Ce que j’ai fait | maj : fait, appelé, attente de retour, dates | une phrase |
| **Reçu** | Demande que j’ai reçue | extraire 1..n tâches + contacts depuis un texte | **mail / SMS** |
| **Envoyé** | Ce que j’ai envoyé | noter l’envoi, basculer « j’attends un retour », coller l’extrait dans `notes` | **mail / SMS** |
| **Rédiger** | (nouveau) | **aucun écrit base** sauf si tu valides « sauver dans notes » ; sortie = mail ou ODJ | consigne + éventuellement qui |
| **Libre** | fenêtre libre | **zéro écriture** ; lecture tâches = à toi de dire dans `05` | bavardage / idée |

Si un mode ne te sert pas, barre-le. Si tu en veux un 7ᵉ (ex. **Décaler**), ajoute une ligne en bas.


### Mode par défaut à l’ouverture de l’app

```
[ ] À faire
[ ] Libre
[ ] autre :
```

### Si tu t’es trompé de mode

```
[ ] L’agent a le droit de dire « ça ressemble à Reçu, tu veux que je retire ? » SANS toucher la base
[ ] Il applique bêtement le mode choisi, même si c’est absurde
```

**Conseil :** première case. Ça évite un mail collé en mode Libre qui ne crée rien, sans t’engueuler.
