# 1 — Toi (obligatoire)

Sans ça, l’agent ne sait pas « qui est moi » dans un mail, ni si on cache le nom de ta boîte dans l’intitulé.

Réponds dans le chat, modèle :

```
Je m’appelle : …
On s’adresse à moi aussi comme : … (surnoms, « tu » dans un mail interne)
Mes organisations (exactement comme dans les mails) : Tecmotec, …
```

**Exemple (inventé, à remplacer) :**

```
Je m’appelle : Lee Sin
On s’adresse à moi aussi comme : Lee, L.
Mes organisations : Tecmotec
```

À trancher aussi :

- Tutoie-t-on **tes** collègues dans les mails rédigés par l’agent, et **vous** les externes ? (oui / non / autre règle)
